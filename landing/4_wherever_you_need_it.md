# Wherever You Need It

## Locked Direction

This section should not present Echo as one linear flow.

There is no single correct creation path.

Possible flows:

- thought -> note
- thought -> post
- note -> post later
- notes -> idea -> post
- idea -> post
- draft -> refined post

Voice improves the quality of the post.
Strategy gives clarity and improves ideation.
The user can write from scratch when they already know what they want to say.

The core idea:

**Echo helps at the exact point where you need it.**

```txt
Have a draft?
Refine it until it says what you mean.
```

## Message

Echo should not feel like a rigid workflow.

It should feel like a flexible system that lets the user take exactly what is missing in the moment:

- memory
- clarity
- direction
- idea
- shape
- refinement
