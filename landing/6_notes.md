# Notes

## Working Draft

### Heading

**Keep thoughts usable**

### Subheading

A saved thought should not become another dead note.

### Before Echo

You come back later and the material is still raw.

A voice note.  
A link.  
A screenshot.  
A half-written sentence.

It exists, but you still have to understand it, connect it, and figure out what it could become.

### With Echo

Echo keeps the pieces together as one readable note.

The raw material becomes:

- easy to read and return to
- a source for ideas that are actually yours
- ready to be shaped into a post

### Short UI Version

```txt
Your thought is saved.
But more importantly, it stays usable.
```

### Notes

This section should separate Echo from normal note apps.

Not:

```txt
We store notes.
```

But:

```txt
We keep raw material alive long enough to become something.
```
